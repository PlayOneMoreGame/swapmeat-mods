# SWAPMEAT Mods

The language packs that ship with [SWAPMEAT](https://store.steampowered.com/app/2246060/), and the English text
they were translated from — exported straight from the game every release, so you can **fork this repository
and make your own language mod** from a known-good starting point.

> This repository holds **mods**, not the game — translation text files and their manifests. There's no game
> code, art, or audio here. A mod is reference-only: it changes text the game already has; it never adds new
> content or code.

> **Read-only.** This repository is an export of the **latest SWAPMEAT release**, regenerated by One More Game
> when an update ships; the exact game version, date and source commit are in
> `localization/EXPORT.json` (written by each export). It does not accept pull requests — a change here
> would be overwritten by the next export. Fork it; what you make is yours.

## Use a language pack (no account, no internet needed)

1. Download a pack — click **Code → Download ZIP**, or grab the three files for one language from
   [`localization/official/`](localization/official/) (a `.mod.json` and its two `.csv`s).
2. Drop them in SWAPMEAT's `mods/` folder:
   - **macOS:** `~/Library/Application Support/OneMoreGame/SWAPMEAT/mods/`
   - **Windows:** `%USERPROFILE%\AppData\LocalLow\OneMoreGame\SWAPMEAT\mods\`
3. Launch SWAPMEAT and pick the language in **Options → Language** — a modded language shows `[MOD]` next to its
   name, with the author.

That's the whole thing. It works offline, off-Workshop — the files just have to be in the folder.

## Make your own

Fork this repository and edit the CSVs in your fork. **[CONTRIBUTING.md](CONTRIBUTING.md)** walks through the
file format, the rules that keep a pack loading, and how to ship it — into your own `mods/` folder, to friends,
or to the Steam Workshop so anyone can subscribe.

- **Improve a language SWAPMEAT ships** — start from its pack under
  [`official/`](localization/official/) (e.g. `swapmeat-zh-Hans.UIStrings.csv`).
- **Add a new language** — start from the English source in
  [`_reference/`](localization/_reference/).

Community packs never overwrite the official ones in-game: yours is a separate entry in the language picker,
and anything you haven't translated falls back to the official text, then to English.

## What's here

```
localization/
  EXPORT.json   — which SWAPMEAT release this export came from, and when
  official/     — the languages SWAPMEAT ships (the shipping text, regenerated each release)
  _reference/   — English source strings, to translate a new language from
  glossary.csv  — the established translations of names and key terms the official packs use
scripts/validate — checks a pack's three files agree; run it on your own pack before you ship it
```
